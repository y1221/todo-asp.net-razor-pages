# Todo アプリ

> ASP.NET Core Razor Pages 学習用 Todo アプリケーション

## 📝 関連記事

- [【ASP.NET Core】Razor Pages を使って簡易的な Todo アプリを作った](https://qiita.com/okayu__11/items/acae072098c06ceb2645)

## 🚀 クイックスタート

### 1. リポジトリのクローン

```bash
git clone https://github.com/y1221/todo-asp.net-razor-pages.git
cd your-repo
```

### 2. アプリケーションの起動

```bash
dotnet run --project TodoRazorApp --launch-profile https

# またはVisual Studioから実行
```

### 3. アクセス

https://localhost:7147/Accounts

## 🛠️ 技術スタック

- **言語**: C# 12.0
- **フレームワーク**: .NET 8.0
- **プロジェクトテンプレート**: ASP.NET Core Web アプリ
- **データアクセス**: Entity Framework Core
- **データベース**: SQL Server Express 2019 LocalDB

## ⚙️ 前提条件

- **OS**: Windows
- **ランタイム**: .NET 8.0 ランタイム
- **データベース**: SQL Server (Windows 認証)
